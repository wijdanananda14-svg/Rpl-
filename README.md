1. Sistem Manajemen Tugas Mahasiswa (Task Management)
Deskripsi
Aplikasi untuk mencatat tugas kuliah, deadline, status pengerjaan, dan prioritas tugas.
Fitur Utama
Login/Register
Tambah tugas
Edit dan hapus tugas
Status (Belum Dikerjakan, Proses, Selesai)
Pengingat deadline
Dashboard tugas
Kelebihan
Mudah dipahami semua orang.
UML dan database sederhana.
Banyak ruang pengembangan.
Contoh Evaluasi Teman
Tambahkan notifikasi.
Tambahkan kategori mata kuliah.
Tambahkan kalender akademik.
2. Sistem Reservasi Lapangan Olahraga
Deskripsi
Aplikasi untuk memesan lapangan futsal, badminton, atau basket secara online.
Fitur Utama
Melihat jadwal lapangan
Booking lapangan
Pembayaran (simulasi)
Riwayat pemesanan
Manajemen jadwal admin
Kelebihan
Relasi database cukup menarik.
Cocok untuk menjelaskan proses bisnis.
Banyak diagram UML yang bisa dibuat.
Contoh Evaluasi Teman
Tambahkan rating lapangan.
Tambahkan pembatalan booking.
Tambahkan fitur promo.
3. Sistem Kantin Kampus Online
Deskripsi
Mahasiswa dapat melihat menu kantin dan melakukan pemesanan sebelum datang.
Fitur Utama
Daftar menu
Keranjang belanja
Pemesanan makanan
Riwayat pesanan
Dashboard penjual
Kelebihan
Dekat dengan kehidupan mahasiswa.
Mudah dipresentasikan.
Banyak kemungkinan pengembangan.
Contoh Evaluasi Teman
Tambahkan pembayaran digital.
Tambahkan estimasi waktu.
Tambahkan ulasan makanan.
